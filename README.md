## Краткое описание

RMS — это масштабируемая ERP-платформа для автоматизации розничных сетей, интернет-магазинов и сервисных центров. Система покрывает все ключевые бизнес-процессы:

- Управление товарами, услугами, складами.
- Кассовые операции с фискализацией (ОФД, 54-ФЗ).
- Учёт маркировки «Честный знак» (ввод и вывод из оборота).
- Полный цикл заказов (интернет-магазин, менеджеры, розница).
- Бронирование услуг с ресурсами и расписанием.
- Доставка с курьерами и зонами.
- Интеграция с ЭДО, ЕГАИС, маркетплейсами.
- Налоговая отчётность (книги покупок/продаж, декларации).
- Многоуровневая система уведомлений (email, SMS, push, Telegram).
- Аудит и ролевая модель доступа (RBAC).

Проект построен на современных технологиях и готов к промышленной эксплуатации.

## Основные функции

- ✅ **Справочники и каталоги**: товары, услуги, категории, бренды, контрагенты, склады.
- ✅ **Складской учёт**: поступления, перемещения, инвентаризации, остатки, резервирование.
- ✅ **Касса**: пробитие чеков, возвраты, коррекции, отправка в ОФД, X/Z-отчёты.
- ✅ **Маркировка**: регистрация кодов, проверка, передача в ГИС МТ.
- ✅ **Заказы**: розничные, оптовые, интернет-заказы, резервирование, отгрузка.
- ✅ **Услуги и бронирование**: ресурсы, расписание, запись, напоминания.
- ✅ **Доставка**: зоны, курьеры, трекинг, статусы, интеграция со службами.
- ✅ **ЭДО**: обмен УПД, электронная подпись.
- ✅ **ЕГАИС**: алкоголь, маршрутные листы, акты списания, декларации.
- ✅ **Маркетплейсы**: синхронизация заказов, остатков, цен (Ozon, Wildberries, Яндекс.Маркет).
- ✅ **Налоговый учёт**: книги покупок/продаж, регистры, декларации.
- ✅ **Уведомления**: шаблоны, очередь, история, настройки пользователей.
- ✅ **Безопасность**: JWT, RBAC, аудит, шифрование паролей.
- ✅ **Отчёты**: дашборды, экспорт Excel/PDF.

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Backend** | Go 1.22+, Gin (или Echo), GORM, pgx, golang-migrate, JWT, Redis, Asynq/RabbitMQ |
| **Frontend** | React 18, TypeScript, Tailwind CSS, React Router v6, React Query, Zustand, Axios |

| **Инфраструктура** | Docker, docker-compose, Kubernetes, GitHub Actions, Prometheus, Grafana, ELK/Loki |
| **Документация** | OpenAPI 3.0 (Swagger) |
